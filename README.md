# Lista de Tarefas - Node.js e React

Projeto simples de uma lista de tarefas com backend em Node.js e frontend em React.
Permite ao usuário adicionar, listar e remover tarefas.

# Tecnologias Utilizadas
- Javascript
- Node.js
- Express
- React
- HTML
- CSS

# Funcionalidades
- Adicionar tarefas
- Listar tarefas
- Remover tarefas
